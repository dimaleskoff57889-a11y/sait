# Сайт-визитка — подъёмное оборудование

Одностраничник для ИП (монтаж, ремонт и обслуживание лифтов и подъёмников, Москва).

## Запуск

```
npm run dev      # локально, http://localhost:3000
npm run build    # статика в папке out/
```

`npm run build` даёт чистый статический сайт в `out/` — Node на проде не нужен,
папку можно положить на любой хостинг или на VDS за Caddy.

## Где что лежит

- **[`SITE.md`](SITE.md) — бриф: анкета для папы с ответами, решения, что осталось до запуска.**
- **`src/content/site.ts` — весь текст и данные сайта.** Только этот файл нужно
  редактировать, когда придут ответы от папы. Номера вопросов в комментариях — от
  старой анкеты; актуальное соответствие «вопрос → поле» — в `SITE.md`.
- `src/components/*` — блоки страницы. Каждый блок сам прячется, если данных
  для него нет, поэтому сайт не разваливается на неполном контенте.
- `src/app/globals.css` — палитра. Серо-синий `steel` + сигнальный `signal`.
  Когда будет фото рабочей спецовки — берём с него реальный цвет и правим
  `steel-700/800/900`, весь сайт перекрашивается сам.
- `public/photos/` — фотографии, `public/docs/` — сканы документов.
- `src/app/privacy/page.tsx` — политика обработки ПДн, пока болванка; черновик полного текста — `drafts/privacy-page.tsx.draft` (к сайту не подключён).
- `src/components/LiftIllustration.tsx` — схема подъёмника на первом экране, пока нет фото.
- `src/components/PhotoDeck.tsx` — стопка фото со свайпом в любую сторону: «О мастере» (`site.gallery`) и «Объекты» (`ObjectsShowcase.tsx`, фото — `objects[i].photo`).
- `src/components/LogoMark.tsx` — знак «Шахта»; `MessengerButtons.tsx` + `MessengerIcons.tsx` — кнопки Telegram и MAX у номера; `PartnersTicker.tsx` — бегущая строка компаний (логотипы — `public/logos/`).
- Анимации: стили — в конце `src/app/globals.css`; `RevealObserver` (появление при прокрутке), `CountUp` (счётчик), `PartnersTicker` (бегущая строка), `FloorIndicator` («пульт лифта» справа).
- `src/app/og.png/route.tsx` — картинка-превью ссылки для мессенджеров; `robots.ts`, `sitemap.ts`, `icon.svg` — служебное.
